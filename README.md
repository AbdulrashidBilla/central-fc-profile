# Central Football Club — The Walls

GitHub Pages-ready encyclopedic profile and visual history of Central Football Club, established in 2012.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **everything in this folder**, preserving the `assets` folder.
3. Make sure `index.html` is at the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose the branch containing `index.html`, and save.
6. GitHub will provide the Pages address for the site.

The profile is deliberately a single encyclopedic article with photographs integrated into relevant sections rather than a separate photo gallery.
